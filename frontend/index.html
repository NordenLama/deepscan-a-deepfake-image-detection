Diagnostic Architecture

How the detection pipeline works

A local feature pipeline that crops faces, computes HOG/LBP descriptors, and compares supervised classifiers.

STAGE 01

Face Extraction & Alignment

Detects and crops the largest face with an OpenCV Haar Cascade, then resizes it to 128×128. If no face is found, a centered square crop is used.

STAGE 02

HOG & LBP Feature Extraction

Builds Histogram of Oriented Gradients (HOG) and Local Binary Pattern (LBP) features to represent facial shape and texture.

STAGE 03

Classification & Heatmap

The selected classifier returns real/fake probabilities. A soft-voting ensemble combines model probabilities; the gradient overlay is a visual aid, not a model explanation.
